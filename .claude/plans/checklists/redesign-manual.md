# 재개편 수동 회귀 체크리스트

> 자동 게이트(V1 스모크 · V2 특성화 · V4 잔재 · V5 CSS변수 · V6 대비)가 못 잡는 것만 담는다.
> **단계마다 전량 재수행하지 않는다** — 그 단계가 건드린 영역의 항목만 확인한다.
>
> 확인 환경: worktree(`taxback365-redesign`)를 3001, main 을 3000 에 띄우고 나란히 비교한다.
> 테스트가 없는 프로젝트라 이 좌우 비교가 사실상 유일한 시각 회귀 판정 수단이다.

## 왜 자동화하지 않았나

| 항목 | 자동화 불가 사유 |
|---|---|
| 스크림 반전 | 렌더 결과의 겹침 관계는 정적 분석으로 판정 불가. `bg-base/80` grep 은 존재만 알려주고 "흰 위 흰"인지는 모른다 |
| 모달 개폐 | 클릭 경로가 필요. Playwright 는 조판 확정 후 도입 예정(설계 §5.3) |
| 인증 상태별 nav | 세션 쿠키가 필요 |
| 모바일 탭바 | 뷰포트 의존 |
| 계산기 화면 숫자 | 총환급액이 JSX 안에만 존재해 lib 특성화 테스트가 못 덮는다 |
