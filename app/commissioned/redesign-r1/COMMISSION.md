### 왜 이 방향인가 — 결정 경위
기존은 off-black + electric mint(Premium Dark Fintech, `a06aa75`)였다. 사용자가 "완전히 새 방향"을 선택해 네 후보(페이퍼 / 인디고+골드 / 스위스 그리드 / 라이트+그린)를 제시했고 **1차로 인디고+골드**를 골랐다.

시안 완성 후 사용자가 두 가지를 지적했다:
1. **"상단·하단 푸터는 기존 그대로인가?"** — 그랬다. 시안이 `components/layout/*`를 건드리지 않아 Nav/Footer가 옛 팔레트(off-black + mint)로 남았고, 본문(인디고+골드)과 **민트 vs 골드로 정면 충돌**했다. 범위 설정 착오였다 — 스코프를 라우트 단위로만 나눴는데 셸은 모든 페이지에 나타나는 공유 요소였다.
2. **"처음에 인디고로 설정했잖아. 다시 선택할 수 있게 가능한가?"** — 색이 전부 `--cx-*` 스코프 변수이고 tsx에 raw hex가 0이라, 변수 세트 교체만으로 전환이 가능했다.

**최종 결정: 스위스 그리드를 기본으로, 셸은 본문과 구분되는 잉크 블랙 면.**

### 셸 면 — `.cx-shell` 스코프 재정의

**원칙: 셸은 본문의 반대 명도 면.** 셸 컴포넌트의 tsx는 `--cx-*`만 참조하므로 스코프 재정의만으로 면이 바뀐다.

| | 본문 base | 셸 base | 경계 대비 | 셸 fg | 셸 muted | 셸 accent |
|---|---|---|---|---|---|---|
| **swiss** ★ | `#FFFFFF` | `#F2F2F2` | 1.12 (면) + **17.69** (규칙선) | `#0A0A0A` 17.69 | `#5A5A5A` 6.16 | `#D92D33` 4.29 / ink `#C0242A` 5.32 |
| indigo | `#0E1230` | `#252C60` | 1.41 (lift) | `#F2F1EA` 11.53 | `#A9B2D2` 6.21 | `#E0B15C` 6.60 |
| paper | `#F7F4EE` | `#1C1A15` | 15.84 | `#F7F4EE` 15.84 | `#9E978A` 6.00 | `#7FA878` 6.44 |
| forest | `#FBFBF9` | `#111E18` | 16.58 | `#FBFBF9` 16.58 | `#93A099` 6.32 | `#4FBF8B` 7.49 |

**판단 근거**
- **indigo만 반전하지 않는다.** 다크 본문에 밝은 셸을 얹으면 "스타일이 안 먹은 화면"으로 읽히고, 더 어둡게 가는 길은 **물리적으로 막혀 있다** — base `#0E1230`(L=0.00718)에서 순수 검정까지 내려도 대비 상한이 1.14:1이다(WCAG 플레어 상수 0.05). 그래서 위로 들어올린 `#252C60`을 쓰고, 4종 중 유일하게 헤어라인이 경계를 실질적으로 보강한다.
- **paper·forest는 accent를 셸용으로 올려야 했다.** 원 accent가 잉크 면 위에서 각각 2.35:1 / 2.81:1로 3:1 미달이라 회원가입 버튼 면과 브랜드 마크가 사라진다. 같은 색상환에서 명도만 올렸다.
- **swiss 셸은 1차로 순흑 `#0A0A0A`(경계 19.80:1)였다가 연회색 `#F2F2F2`로 낮췄다.** 사용자 지적: *"상하단 영역 팔레트가 너무 검정색인 거 아냐?"* — 타당했다. Footer는 `py-16` 4열이라 면적이 커서 검정 덩어리가 페이지 하단을 눌렀고, **순수한 스위스 그리드 관습은 흰 바탕 + 검정 타이포 + 규칙선이지 셸을 검정 면으로 채우는 것이 아니다**(그건 현대 웹 관습에 가깝다).
  → **면은 낮추고 경계는 선이 맡는다.** 면 대비는 1.12:1로 미묘해지고, 새 토큰 `--cx-shell-rule`(#0A0A0A, 17.69:1)이 바깥 경계를 긋는다.
- **`--cx-shell-rule` 신설 이유**: `--cx-edge`가 셸에서 **바깥 경계**(Nav `border-b`·Footer `border-t`)와 **내부 헤어라인**(© 구분선·외부링크 칩)에 함께 쓰이고 있었다. swiss에서 규칙선만 검정으로 강조하려면 분리가 필요했다. 나머지 3팔레트는 면 대비만으로 경계가 완결되므로 `shell-rule = edge`로 두어 렌더가 바뀌지 않는다(어두운 면 안쪽의 어두운 선 = 이중선 아티팩트 회피). **4팔레트 전부에 선언**해 미정의 회귀를 막았다.
- **swiss accent는 연회색 면 위 4.29:1** — 비텍스트 3:1은 넘지만 본문 4.5:1은 미달이다. 버튼 면·마크·포커스링 용도로만 쓰고, 셸 소형 텍스트용으로 `--cx-accent-ink: #C0242A`(5.32:1)를 별도로 뒀다.
- **Nav를 불투명으로 바꿨다** (`backdrop-blur` 제거). sticky라 본문이 밑으로 지나가는데 반투명이면 셸 면 색이 스크롤에 따라 흔들려 "구분된다"는 목적 자체가 깨진다. swiss에서 `rgba(10,10,10,0.85)` 위로 흰 본문이 비치면 실효 면이 `#2E2E2E`가 되어 셸 muted가 4.20:1로 내려간다.
- **경계는 헤어라인이 아니라 면이 담당한다.** `border-b`/`border-t`는 그대로 두되 색이 셸 스코프의 `--cx-edge`라, 라이트 3종에서는 어두운 면 안쪽의 어두운 선(= 이중선 아티팩트 없음), indigo에서는 실제 구분선으로 각각 다르게 작동한다.

### 전환 패널 — 제거됨 (2026-08-09)

비교용 임시 도구였다(우하단 `fixed`, 실제 radio + `fieldset`/`legend`, `localStorage` 키 `cx-r1-palette`). **사용자가 스위스 그리드로 확정하면서 제거**했다:

① `layout.tsx`에서 `<PaletteSwitcher />` + import 삭제 ② `_components/PaletteSwitcher.tsx` 삭제 ③ `commission.css`의 `[data-swatch]` 블록 + indigo·paper·forest 본문/셸 블록 삭제 ④ 남은 셀렉터에서 `[data-palette="swiss"]` 그룹 해제.

**나머지 3종 선언도 함께 지웠다.** 패널이 없으면 `data-palette` 속성을 설정할 수단이 없어 도달 불가능한 죽은 CSS가 되기 때문이다(`commission.css` 598 → 339줄). **위 §5-B의 색값·대비 실측표가 복원용 기록**이므로 필요하면 되살릴 수 있다.

잔존 확인: `PaletteSwitcher` · `data-palette` · `data-swatch` · `--sw-*` · `localStorage` 참조 **전부 0건**.

### 남아 있는 미사용 토큰 (의도적 미정리)

`--cx-accent-10` · `--cx-alert-14` 는 tsx·CSS 어디에서도 참조되지 않는다. 다만 **팔레트 정리 이전부터 미사용**이었고 이번 변경이 만든 orphan이 아니므로 건드리지 않았다(surgical 원칙: 본인 변경이 만든 orphan만 정리). `--cx-accent-ring`(슬라이더 포커스링 2회)과 `--cx-glow-image`(`.cx-glow::before` 1회)는 CSS 내부에서 사용 중이라 살아 있다.

### 이 라운드에서 잡은 회귀

designer가 팔레트 작업 중 `commission.css`를 재작성하며 **`--cx-brand-google-*` 4종을 유실**했다. `AuthBits.tsx`는 계속 참조 중이었고, 정의 없는 변수를 `fill`에 쓰면 SVG가 **검정으로 폴백**해 인디고 배경에서 로고가 사라진다. **타입체크·린트·static-check 어디에도 걸리지 않는 유형**이다.

→ 토큰을 `.cx-r1` 공통 블록에 복원(팔레트·셸 어디서도 재정의 안 함)하고, **tsx의 `var(--cx-*)` 참조 전체와 CSS 선언을 대조하는 검사**를 절차로 추가했다. 현재 참조 22종 / 미정의 **0건**.
